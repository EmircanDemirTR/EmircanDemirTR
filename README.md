## Hakkımda

Kocaeli Üniversitesi Bilişim Sistemleri Mühendisliği'ni 2026'da onur derecesiyle tamamladım; lisans yıllarımda hazırladığım araştırma projesi TÜBİTAK 2209-A desteği aldı.

Ağırlıklı olarak Java, yanı sıra .NET ve C# ile backend servisleri geliştiriyorum. Son dönemde odağım dil modellerinde: RAG mimarileri kuruyor, embedding modellerini ve parçalama stratejilerini vektör veritabanı üzerinde karşılaştırarak ölçüyorum. Yazdığım işi Docker ile konteynerize edip GitHub Actions üzerinden Linux sunuculara yayına alıyorum.

Öğrendiğimi paylaşmayı işin bir parçası sayıyorum. Deneyap Teknoloji Atölyeleri'nde üç yıl boyunca yüzlerce gence yazılım, robotik, yapay zekâ ve IoT dersleri verdim; BTK Akademi'de iki makine öğrenmesi eğitimi, Udemy'de "JAVA ile Yapay Zeka Mühendisliği" serisini hazırladım.
